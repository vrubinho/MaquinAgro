## 📌 Sobre o projeto

O **MaquinAgro** é uma plataforma desenvolvida com o propósito de facilitar o acesso de pequenos produtores rurais a máquinas e equipamentos agrícolas por meio de um sistema de aluguel.

A proposta busca reduzir barreiras financeiras, permitindo que produtores tenham acesso aos equipamentos necessários para melhorar sua produtividade sem precisar investir na compra de máquinas próprias.

O projeto faz parte do desafio acadêmico **FIAP Agrotech**, alinhado ao Objetivo de Desenvolvimento Sustentável (ODS) 2 — Fome Zero e Agricultura Sustentável.

## 🎯 Objetivos

- Facilitar o acesso de pequenos produtores a máquinas agrícolas.
- Conectar produtores e proprietários de equipamentos.
- Incentivar o compartilhamento de recursos.
- Contribuir para uma agricultura mais acessível e sustentável.

## ✨ Funcionalidades

- 🏡 Página inicial com apresentação da plataforma.
- 🚜 Apresentação de máquinas e equipamentos agrícolas.
- 🔎 Experiência de navegação intuitiva.
- 📋 Informações sobre o funcionamento da plataforma.
- 📱 Interface pensada para diferentes dispositivos.

*As funcionalidades estão em desenvolvimento e podem receber atualizações ao longo do projeto.*

## 🚀 Como executar o projeto

1. Clone o repositório:

   ```bash
   git clone https://github.com/LiedsonF/MaquinAgro.git
   ```

2. Entre na pasta:

   ```bash
   cd MaquinAgro
   ```

3. Abra o projeto no VS Code:

   ```bash
   code .
   ```

4. Execute o arquivo `index.html` utilizando a extensão **Live Server**.
